# 全局学习、应用分组与手动维护（2026-10-05）

默认使用即时全局学习，记录保留分组和应用标签，读取排序时忽略标签。开启“按应用分组的输入习惯”后，才读取当前组的学习数据。AI 默认关闭，维护无常驻进程。**源码已接入；本轮未构建、迁移真实词库、测量速度或验证跨应用同步。**

## 数据职责

librime 仍负责官方学习公式、候选排序和 undo。固定源码内新增 SQLite 存储，实现 rime::Db 接口；精确匹配的源码补丁将同一官方 UpdateEntry 实现分别作用于全局和分组范围，不另写学习公式。接口通过附加 C 导出连接 Rust，不跨 DLL 传递内部 C++ 对象。

学习文件按 Rime 字典身份的 SHA-256 命名，位于 `%ProgramData%/MYIME/users/<Windows SID>/learning`。同一用户、同一字典身份的多个应用读写同一文件，不直接让多个进程打开同一 LevelDB。不同字典和编码身份保持隔离；切换方案不意味着所有用户字典可以无条件互换。

每次成功学习同时更新全局和当前组记录，并保留应用完整路径标签。默认使用全局；按组模式只使用该组学习，不按单独 EXE 分裂每个词库。关闭按组模式后重新使用全局，已有标签和组记录保留。

SQLite WAL 支持并发读取、序列化写入；每个原生事件结束释放读快照，成功提交后其他应用下一次查询使用。未提交的已有候选页不强行重新排序。写锁最多等待 12 ms；存储失败记录诊断、保留输入/commit，不重放按键。正常写入有同步 I/O 成本，未承诺零延迟。三秒撤销沿用 Rime 时机；并发更新过同一记录时避免用旧快照覆盖其他应用的新学习。

## 分组与切换

“学习与分组”支持工作、日常及自定义组（最多 32 个），完整 EXE 路径映射最多 512 项。没有映射的应用为日常，不按名字猜工作/游戏/专业词典。产品 AppProfile 的 EXE 文件名匹配与学习完整路径映射职责不同。

右键模式图标可以选择工作、日常、自定义组或“跟随应用分组”。手动选择仅存在当前应用内存中，不写固定映射；各 TSF 线程在焦点/定时更新时共享选择，当前草稿继续使用原组，结束后切换。重开应用恢复保存的映射；输入法模块被彻底卸载后内存选择也会重置。若删除了所选自定义组，恢复应用映射。

保留草稿有自己的学习范围，不把暂存草稿改为新组。修改永久分类请在设置中编辑应用映射并保存。

## 手动 AI 建议

启用 AI 工具后仍须主动打开建议窗口、勾选应用并点击请求。只发送勾选项的应用名称、目录及用户定义组，不读取词库、候选、按键或输入正文。

兼容本机 llama.cpp 的 OpenAI-compatible 服务（默认 `http://127.0.0.1:8080/v1`）或在线 HTTPS API。工具不安装模型或启动模型服务；填写实际 endpoint 与模型名。本地 HTTP 仅允许 loopback，在线使用 HTTPS，不跟随重定向；请求与返回有超时和大小限制。

结果只能引用现有组和有效应用索引；用户勾选采用后先写到界面草稿，保存学习设置才持久化。API key 通过 DPAPI CurrentUser 保存在本机工具目录，不复制到展示配置，不能直接搬到另一台机器/账户使用。本版 AI 只做应用分组，不做词典内容分析或自动合并。

## 旧词库与备份

旧版 `%LOCALAPPDATA%/MYIME/rime/slots/<n>/*.userdb` 保留。手动“合并旧词库槽”取得未占用槽的独占租约，使用 Rime 的 UserDbMerger 合并到对应共享字典的全局及日常范围。运行中的旧槽跳过，关闭旧应用后可再合并；合并来源无法确定原应用，不能补造旧历史标签。

大量合并会占写锁，建议暂停输入后运行。同步出现的输入仍正常，但本次学习可能因锁超时未写入。原文件不删、不直接复制覆盖 live LevelDB。每个已完成的字典合并持久化；部分失败不宣称整轮成功。

在线备份使用 SQLite backup API，包含全局、组记录和标签；各字典分别一致，不承诺所有字典同一时刻的跨文件快照。返回成功后才把目录视为完整备份，错误留下的目录需要保留或由用户自行处理。恢复备份入口尚未实现。

“整理存储文件”只执行 passive WAL checkpoint，不在后台持续重写；存在其他读取时可留下未完成页。维护由独立 CLI 完成，设置关闭后没有常驻整理、轮询合并或 AI 进程。

## Windows 访问范围

安装为当前 Windows 用户创建专用本地数据组，并只对 MYIME 的 ProgramData 目录配置 ACL。展示配置/主题只读，学习目录可读写并标记低完整性；条件 ACE 限定为该用户数据组，不将所有用户的学习目录开放给所有 AppContainer。首次安装后需注销再登录让组进入令牌。

依据微软 [AppContainer 访问模型](https://learn.microsoft.com/en-us/windows/win32/secauthz/implementing-an-appcontainer) 与 [条件 ACE](https://learn.microsoft.com/en-us/windows/win32/secauthz/security-descriptor-definition-language-for-conditional-aces-)；SQLite 并发依据 [WAL 文档](https://www.sqlite.org/wal.html)。实际沙箱访问和性能仍须在本机验收；不存在对所有 Windows 应用都绝对有效的保证。
