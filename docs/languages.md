# 界面语言与语言包（2026-10-06）

基础设置和皮肤编辑器上方提供“界面语言”，内置简体中文 `zh-Hans` 与繁体中文 `zh-Hant`。选择立即更新已打开窗口的固定标签、按钮、表头、导航和参数注释，不重建窗口或重新读取草稿。主题名称、用户分组名称、路径、原始配置和输入内容不做翻译。语言栏菜单使用同一份翻译数据。

界面语言与输入方案的简繁输出是两个独立设置；切换界面语言不更换 schema、词库或输入模式。Windows 系统对话框和外部组件的原始诊断文字仍由各自组件提供。

## 存储与加载

- 内置语言包源文件：`windows/settings/languages/zh-Hans.json`、`zh-Hant.json`。同一文件嵌入设置 EXE 和 Rust Core，并复制到安装包 `languages`，避免重复维护。
- 用户语言包：`%LOCALAPPDATA%\MYIME\languages\<id>.json`；指定 `--data-root` 时使用该目录下的 `languages`。
- 语言选择：数据根目录 `ui-language.txt`，以 UTF-8 写入语言 id，同目录临时文件原子替换。
- 用户包覆盖安装包，安装包覆盖内嵌包。简繁包的缺失条目先使用对应内嵌语言，再使用内嵌简体；新语言的缺失条目使用简体。无效包被忽略，点击“刷新语言包”会提示文件名称。
- 添加或修改包后点击“刷新语言包”，无需编译。安装目录无需用户写入权限；建议把自定义包放在用户目录。

## 包接口

UTF-8 JSON，版本 1。id 使用 1–32 位 ASCII 字母、数字或短横线，必须与文件名一致；单包不超过 256 KiB，最多 2048 条消息。每条键最多 512 字符、翻译最多 4096 字符。包只有文字数据，不包含脚本、模板执行或网络链接调用。

```json
{
  "format_version": 1,
  "id": "zh-Hant",
  "name": "繁體中文",
  "culture": "zh-TW",
  "messages": {
    "设置": "設定",
    "同 Windows 设置": "同 Windows 設定",
    "theme.input.background.color.title": "輸入欄背景顏色",
    "theme.input.background.color.description": "輸入欄卡片的實心背景顏色。"
  }
}
```

普通界面消息以源码中的简体原文为消息 id，类似 gettext 的 msgid；皮肤字段采用稳定路径键 `theme.<section>.<key>.title` / `.description`，分类采用 `theme.category.<section>`。参数名、下方说明、方向选择和布尔选择分别翻译，保存值仍为原始 TOML 类型和键。

`UiText.Get(id)` 获取文字；`UiText.Format(id, values)` 使用 `{0}` 等占位符，语言包必须保留所需占位符。没有提供 `culture` 或系统不支持该 culture 时，仍使用包内消息；系统组件保持可用的界面文化设置。

## 输入法菜单与受限应用

设置发布时，只把所选语言 id 和菜单所需消息发布到现有只读展示代，然后广播更新。受限应用不读取私人 API 配置、草稿、完整语言包或用户词库。Host 在激活及设置刷新时读取有界的语言快照，之后菜单与提示使用内存中的自有字符串；按键路径不做语言文件 I/O 或 IPC。没有新增常驻维护程序。

公开 C 接口为 `include/myime/ui_language.h`：加载不可变语言句柄、按消息 id 获取借用的 UTF-8 文本、销毁句柄；句柄限创建线程使用，借用文本有效到销毁。与主题展示 ABI 分开版本化。
