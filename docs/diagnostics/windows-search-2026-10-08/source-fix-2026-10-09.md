## 最终行为

- 安装器在每个受保护的版本目录写入 shared-storage-root.txt，内容为本机 CommonApplicationData 的规范绝对路径，UTF-8 无 BOM，无换行，最大 64 KiB。文件只包含机器级存储基目录，不包含用户 SID。Host、设置发布和手动词库维护读取同一协议；缺少定位文件的旧安装保留 Windows 已知目录查询。SID 始终从有效 TokenUser 取得，不猜测桌面账户或搜索进程名称。
- Host 把工作区选择、Rime 路径编码、已部署基础字典检查、共享身份、安装器路径、学习路径、会话创建和产品配置应用分开记录。原生 API 返回码和 std::exception::what() 跨清理过程保留。文件诊断仍须显式启用；无输入正文日志，没有 DllMain 初始化或 I/O。
- 共享根目录不可解析时，Host 显式传递空学习路径；共享学习目录不存在或无法访问时，Core 可保留官方 Rime 的基础字典输入。空路径禁用用户词库，不创建、迁移或改用私人槽词库，不以相对路径写入工作目录。原有共享词库文件及其 ACL 保留。
- Rime 上游翻译器在用户词库未加载时仍使用基础字典。存储包装器额外保护查询、提交和删除：用户词库未加载时跳过访问，避免 Memory 的提交回调解引用空库。存储错误不重放按键、不丢弃已经产生的提交；正常回滚不再被误标为学习故障。
- 共享展示选择器不可读或无效时使用当前进程的本地设置和主题来源。共享配置读取失败时同样降级，并在本次激活期间保留这个决定。本地配置不存在时沿用 Core 已有默认值；本地配置本身无效仍报错。共享设置不可用时，跨应用设置和皮肤同步不保证生效。
- myime_learning_available 为新增 ABI v1 导出；仅原子内存读取，不访问文件或使用 IPC。学习错误状态与一次性错误码分开，失败提示保守保留到 Rime 运行时重新初始化。可用时继续原有即时全局学习；没有常驻维护程序或新增按键路径 IPC。
- 模式图标提示及右键菜单显示“共享学习不可用；基础输入可继续”和“共享设置不可用；使用本地设置”。简繁中文语言包及共享展示投影包含对应翻译，异常状态下停用学习分组选项。

损坏的工作区选择器、自定义工作区缺失或未部署的 schema 仍属于必需输入数据错误，明确记录并失败；不会静默改选其他工作区或修写用户字典。此类失败若在新日志中出现，还需对实际工作区做针对性修复。

## 下一台机器的交接要求

源码阅读不能代替构建和真实输入验收。本轮没有验证编译兼容性、目标 AppContainer 权限、开始菜单焦点切换、候选位置或输入提交。获得用户新的构建、安装和测试授权后，再执行这些工作。

须完整重新构建和打包 Host、Core、配套 librime 与设置程序，并使用本轮安装器。原生存储实现及 patch 脚本已变化，现有构建指纹会使 librime 缓存失效；不得仅替换 Host DLL 或复用旧 out 包。旧版二进制和旧安装器没有本轮路径发布和降级能力。

若仍失败，先读新日志的逐阶段信息。工作区或基础字典错误应停在对应必需步骤；共享身份、定位文件或目录权限问题应显示具体错误并进入可选功能降级；之后出现的候选 UI 或 TSF 注册错误应另外判断。原始跟踪继续只保存在本地，不提交用户路径、SID、输入内容或私人词库到公开仓库。

微软文档说明 IME DLL 受所在应用相同的 AppContainer 约束，Program Files 可用于可读的安装数据；此次只减少路径发现依赖，仍遵守实际目标资源的访问控制：

- [Microsoft IME requirements](https://learn.microsoft.com/en-us/windows/apps/develop/input/input-method-editor-requirements)
- [SHGetKnownFolderPath](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shgetknownfolderpath)

上游行为参考本地固定版本 librime 的 UserDictionary::Load、Memory::OnCommit 和 ScriptTranslator::Query；已有的产品存储包装器负责在不可用状态下跳过学习，不改变 Rime 的字典排序公式。
